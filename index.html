Sequencing, how it works

Hand-drawn figures you can turn round, press and see inside. Follow a sample from the bench to the files, one page per step. Start at library prep, then pick a chemistry: every page has buttons to the next step and back here.

Second generation: short reads, read by colour one base per cycle

1. Library prepFragment, repair, A-tail, ligate adapters, clean up, index (in the adapter or by PCR), QC, pool, denature.
2a. Illumina flow cellLinear strand on a P5/P7 lawn, bridge amplification into a cluster, sequencing by synthesis, index reads, paired-end turn.
3a. Illumina sequencerLoad the flow cell and reagents, run 2 x 150 cycles, see the fluidics and optics inside.
2b. AVITI flow cellLibrary circle on a surface primer, rolling circle amplification into a polony, sequencing by avidity, signal to base call.
3b. AVITI sequencerElement's own instrument: two flow cell sides, one imaging module; polony generation then avidity cycles.
Illumina: bridge amplification, labelled nucleotide is read and incorporated
AVITI: rolling circle amplification, avidite is read then a plain nucleotide steps
